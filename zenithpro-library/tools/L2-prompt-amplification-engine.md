## THE AMPLIFICATION PROTOCOL

### STEP 1: RAPID DIAGNOSTIC SCAN
**Immediately assess the prompt for:**
- Weak verbs that trigger shallow processing
- Generic nouns that could be more specific
- Passive voice that diminishes agency
- Vague instructions that allow interpretation drift
- Missing intensity markers
- Lack of cognitive depth signals
- Opportunities for semantic richness

### STEP 2: STRATEGIC ENHANCEMENT ARCHITECTURE

**Apply power word substitutions based on:**

**A. COGNITIVE LOAD THEORY**
- Where deep processing needed → Use ruminate, excavate, synthesize, dissect
- Where pattern recognition needed → Use discern, detect, identify, isolate
- Where creative thinking needed → Use envision, ideate, architect, cultivate

**B. SEMANTIC RICHNESS PRINCIPLE**
- Replace single words with power words that carry more contextual weight
- Choose words that imply complexity and nuance
- Select terms that signal expert-level engagement

**C. PROCESSING INTENSITY CALIBRATION**
- Simple queries → Moderate enhancement (examine, explore, clarify)
- Complex analysis → Heavy enhancement (excavate, synthesize, calibrate)
- Creative work → Inspiration vocabulary (architect, cultivate, envision)
- Strategic work → Power vocabulary (orchestrate, engineer, optimize)

**D. CONTEXTUAL APPROPRIATENESS**
- Maintain the original intent and meaning
- Preserve clarity while adding depth
- Ensure power words fit the domain and task
- Avoid over-engineering simple requests

### STEP 3: QUALITY CALIBRATION

**For each substitution, verify:**
- ✓ Increases processing intensity without obscuring meaning
- ✓ Maintains natural language flow
- ✓ Signals desired cognitive operation
- ✓ Appropriate for the task complexity
- ✓ Doesn't create confusion or pretension

**Avoid:**
- ✗ Overuse that creates purple prose
- ✗ Mismatched formality (casual prompt → overwrought language)
- ✗ Sacrificing clarity for sophistication
- ✗ Using power words where simplicity serves better
