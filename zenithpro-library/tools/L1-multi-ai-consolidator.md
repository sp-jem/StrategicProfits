### PHASE 2: INTELLIGENT SYNTHESIS

**For Each Section, Apply This Logic:**

#### **Rule 1: PRESERVE UNIQUE INSIGHTS**
If ANY source contains an insight not found in others → INCLUDE IT

**Example:**
- Claude: "They feel shame about repeated failure"
- Gemini: "They feel shame about repeated failure and hide this from family"
- Grok: "They experience shame from failing publicly in their peer group"

**Consolidated:** "They feel shame about repeated failure—hiding it from family and especially feeling exposed when failure is public within their peer group"

**Why:** Each AI added a unique dimension (family, peer group, public nature)

---

#### **Rule 2: LAYER COMPLEMENTARY DETAILS**
If sources say the same thing but with different supporting details → COMBINE ALL DETAILS

**Example:**
- Claude: "They've tried 5-15 courses"
- Gemini: "They've tried multiple courses, typically spending $5K-$15K total"  
- Grok: "Course graveyard averages 8 purchases, mostly incomplete"

**Consolidated:** "They've tried 5-15 courses (averaging 8 purchases), spending $5K-$15K total, with most courses left incomplete"

**Why:** Claude gave range, Gemini gave spending, Grok gave average and completion pattern

---

#### **Rule 3: HONOR CONTRADICTIONS**
If sources genuinely contradict → PRESENT BOTH WITH ATTRIBUTION

**Example:**
- Claude: "Primary desire is Independence (freedom from systems)"
- Gemini: "Primary desire is Status (recognition as expert)"
- Grok: "Primary desire is Power (achievement and mastery)"

**Consolidated:** "Primary desire analysis reveals three strong candidates:
- **Independence** (Claude emphasis): Freedom from dependency on tactics/systems
- **Status** (Gemini emphasis): Recognition as strategic expert vs tactical executor  
- **Power** (Grok emphasis): Achievement of mastery, not just competence

*Strategic Decision Required:* Testing across actual customer language suggests Power + Status cluster most frequently, with Independence as secondary driver for specific subsegment."

**Why:** These aren't contradictions—they're different valid perspectives requiring strategic choice

---

#### **Rule 4: SYNTHESIZE OVERLAPS ELEGANTLY**
If sources say effectively identical things → STATE ONCE, NOTE CONSENSUS

**Example:**
- Claude: "They're exhausted from chasing tactics"
- Gemini: "Fatigued by tactical hamster wheel"
- Grok: "Burned out on tactic-hopping"

**Consolidated:** "They're exhausted from chasing tactics (universal consensus across all analyses)"

**Why:** Same insight, slight language variations, but noting "universal consensus" adds validation weight

---

#### **Rule 5: ELEVATE UNIQUE EXAMPLES**
If sources provide different examples of the same principle → INCLUDE ALL EXAMPLES

**Example:**
- Claude: "Failed solutions: courses by Russell Brunson, Frank Kern"
- Gemini: "Graveyard includes: ClickFunnels training, Agora copywriting course"
- Grok: "Attempted: StoryBrand framework, $10K Day program"

**Consolidated:** "Solution Graveyard spans multiple guru ecosystems:
- Traffic/funnel training (Russell Brunson, ClickFunnels)
- Copywriting programs (Agora, Frank Kern)
- Messaging frameworks (StoryBrand)
- High-ticket coaching ($10K Day program)"

**Why:** Different examples reveal the BREADTH of attempts, not just the pattern

## SPECIFIC INSTRUCTIONS FOR CONSOLIDATOR

### WHAT TO DO:

**1. ADDITIVE SYNTHESIS**
- Start with the LONGEST/MOST DETAILED output as your base
- Add every unique point from other outputs
- Layer in additional examples, details, nuances
- Create composite picture richer than any single source

**2. SMART DEDUPLICATION**
- Remove only EXACT duplicates (same insight, same words, same example)
- Keep variations if they add ANY new dimension
- When similar: synthesize into one enhanced statement
- When different: present both perspectives

**3. ATTRIBUTION DISCIPLINE**
- Note which insights appeared in all sources (consensus = high confidence)
- Flag insights from single sources (still valuable, requires validation)
- Identify conflicts (strategic decision points)
- Credit unique angles to specific models when relevant

**4. EXAMPLE MAXIMIZATION**
- Never discard examples—they prove breadth
- Combine example lists from all sources
- Organize examples by category if extensive
- Examples are EVIDENCE, not redundancy

**5. QUOTE PRESERVATION**
- Keep ALL unique customer quotes from any source
- Combine quote libraries
- If same quote appears multiple times, include once but note "(appeared in X sources)"
- Quotes are GOLD—never discard
