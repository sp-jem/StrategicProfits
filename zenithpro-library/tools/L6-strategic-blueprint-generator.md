## PURPOSE

This tool generates a comprehensive strategic blueprint for installing a belief sequence from your Belief Path Mapper. Unlike traditional content generators that output finished scripts, this creates a MASTER BLUEPRINT that can be adapted to any format - webinar, 3-day challenge, email sequence, sales page, video series, podcast, live event, or anything else.

**Critical Design Principle:** 90% of influence happens below conscious awareness. Every blueprint element must be designed for INVISIBLE INSTALLATION—where belief shifts occur without the audience consciously noticing they're being persuaded.

**What You Get:** 
- Complete strategic architecture with invisible influence layers
- Raw content assets with S.U.C. scoring
- Installation requirements with micro-commitment sequences
- Delivery guidance with tension design
- Format adaptation matrices with M.W.A. customization
- Polarization architecture for identity-level beliefs
- Context frame specifications
- Quick win options for experiential proof

**What You Don't Get:** Finished scripts. You take this blueprint and adapt it to your chosen format yourself or with a team.

## AI PROCESSING INSTRUCTIONS

You are creating a strategic blueprint for INVISIBLE BELIEF INSTALLATION - not a finished script. Your output must be format-agnostic and provide complete strategic architecture that can be adapted to any delivery format.

### STEP 1: PATH ARCHITECTURE ANALYSIS

Extract from Belief Path Mapper:
- Complete bridge sequence with S.U.C. scores
- Bridge metrics (cognitive load, certainty, emotional difficulty)
- Current belief → Bridge belief transformations
- Evidence requirements per bridge
- Objection points per bridge
- Path-level metrics
- M.W.A. focus
- Invisible influence layers (if available)
- Micro-commitment sequences (if available)

Analyze strategic implications:
- Why this sequence works (psychological progression)
- Where momentum builds naturally
- Where resistance will peak
- What dependencies exist between bridges
- Where Point of No Return occurs
- How polarization strengthens attraction

### STEP 2: INSTALLATION REQUIREMENTS SPECIFICATION

For each bridge belief, determine:

**S.U.C. Scoring:**
- Strong (1-10): Does this bridge make a powerful, specific promise?
- Unique (1-10): Is this angle different from everything else?
- Compelling (1-10): Does it create must-know curiosity?
- If any <7, provide revised bridge angle

**Installation Difficulty:**
- Cognitive load + Emotional difficulty = Total installation challenge
- High challenge = needs more time/space/support
- Low challenge = can move quickly

**Invisible Influence Design:**
- SURFACE (10%): What they consciously experience
- CONTEXT LAYER (25%): Environmental framing that shapes interpretation
- IDENTITY LAYER (30%): Who they become by accepting this
- BELIEF LAYER (25%): The actual belief being installed
- DESIRE LAYER (15%): Existing desire being channeled toward solution

**Installation Vehicles (Expanded):**
- Story (emotional installation through narrative identification)
- Data (logical installation through evidence)
- Logic (rational installation through reasoning)
- Demonstration (experiential installation through witnessed result)
- Authority (credibility installation through trust transfer)
- Environment (contextual installation through frame)
- Micro-commitment (sequential installation through small agreements)
- Polarization (identity installation through tribal belonging)

**Micro-Commitment Design:**
- What small agreement precedes this belief?
- What identity statement does accepting imply?
- Psychological momentum contribution
- Point of No Return assessment

**Context Prerequisites:**
- Environmental frame required
- Narrative frame required
- Social frame required
- Authority frame required
- What would break the frame

**Tension Design:**
- TEACH (70%): What complete insight is given?
- WITHHOLD (30%): What creates hunger for more?
- Questions planted
- Strategic incompleteness

**Quick Win Options:**
- What result could they experience in <5 minutes?
- What demonstration proves this belief?
- How can they SEE it work before fully accepting?

**Polarization Elements (for identity-level bridges):**
- Who is this FOR?
- Who is this NOT FOR?
- Tribal signal sent
- Does this belief have enemies?

**M.W.A. Variations:**
- If audience is Low-M: How to adjust
- If audience is Low-W: How to adjust
- If audience is Low-A: How to adjust

**Installation Success Criteria:**
- What signals indicate this belief has landed?
- What would failure to install look like?
- How to test if installation worked?

### STEP 3: CONTENT ASSET MATCHING

Match proof assets to bridges with S.U.C. optimization:
- Which stories support which bridges? (Score each for S.U.C.)
- Which data supports which bridges? (Score each for S.U.C.)
- Which authority references support which bridges?
- Which demonstrations support which bridges?
- Which polarization assets support which bridges?

Rank by impact/credibility/accessibility AND S.U.C. score.

### STEP 4: STRATEGIC DELIVERY MAPPING

Identify:
- **High-leverage moments:** Where small input = big shift (often at Point of No Return)
- **High-risk moments:** Where drop-off/resistance likely
- **Pacing zones:** Fast vs. slow delivery areas
- **Interaction requirements:** Where engagement necessary vs. optional
- **Micro-commitment insertion points:** Where to request small agreements
- **Tension management:** Where to teach vs. withhold
- **Transition architecture:** How bridges connect naturally
- **Polarization moments:** Where to signal tribal identity

### STEP 5: FORMAT ADAPTATION GUIDANCE

For each bridge, specify format-specific invisible influence design:
- **If webinar:** Time allocation, interaction needs, slide needs, micro-commitment moments
- **If 3-day challenge:** Day assignment, daily action (quick win), community element, tension across days
- **If email sequence:** Email count, subject line S.U.C., CTA approach, cliffhanger design
- **If sales page:** Section structure, proof placement, scroll-based tension, polarization placement
- **If video series:** Episode structure, hooks (S.U.C. optimized), cliffhangers, Point of No Return episode
