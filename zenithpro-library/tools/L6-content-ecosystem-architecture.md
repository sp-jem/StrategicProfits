```
### PART 7: TESTING & AMPLIFICATION PROTOCOL

```
### ORGANIC TESTING (Weeks 1-4)

**Metrics to Track:**

INVISIBLE INFLUENCE INDICATORS:
- Save rate (highest signal - they want to return to this)
- Share rate (they want others to experience this shift)
- Comment quality (look for belief-shift language):
  - "I never thought of it that way" = belief shifted
  - "This is exactly what I needed" = identity resonance
  - "Tagging [person]" = tribal spread
  - "Where do I learn more?" = tension working
  - Debate/disagreement = polarization working

VISIBLE PERFORMANCE INDICATORS:
- Watch completion (attention held)
- Profile visits (curiosity about source)
- Follow rate (want more)
- Click-through (ready for next step)

S.U.C. PERFORMANCE CORRELATION:
- Track which S.U.C. scores correlate with which metrics
- Hypothesis: High-S → saves, High-U → shares, High-C → comments

**Winner Identification:**

A piece is a "WINNER" if:
- Exceeds 2x baseline on any key metric AND
- Shows qualitative signals of belief shifting in comments AND
- S.U.C. score was 7+ (validates framework)

A piece is a "LEARNER" if:
- Underperformed despite high S.U.C. scores
- Analyze: Was context wrong? Polarization too weak? Tension imbalanced?

### INVISIBLE INFLUENCE OPTIMIZATION

For each content batch, audit:
- [ ] Did SURFACE presentation match platform expectations?

- [ ] Did IDENTITY layer offer attractive transformation?
- [ ] Was BELIEF LAYER installed invisibly (no defensive comments)?
- [ ] Did DESIRE LAYER connect to existing wants?
