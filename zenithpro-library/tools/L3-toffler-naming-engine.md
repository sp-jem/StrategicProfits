## STRUCTURAL FORMULAS

### **ALVIN TOFFLER PATTERNS**

**Formula 1: Compound Neologism**

```
[Concept A] + [Concept B] = New Word
Examples: Future + Shock | Pro + sumer | Ad + hocracy
```

**Formula 2: "The ___ ___" (Adjective + Noun)**

```
The + [Provocative Adjective] + [Core Noun]
Examples: The Throwaway Society | The Modular Man | The Fractured Family
```

**Formula 3: "The ___ Wave/Age/Era"**

```
The + [Ordinal Number] + [Epochal Noun]
Examples: The Third Wave | The Second Self
```

**Formula 4: "Over-___" (Excess Pattern)**

```
Over + [Core Concept]
Examples: Overchoice | Overstimulation
```

**Formula 5: Numbered Metaphor**

```
The + [Large Number]th + [Time/Life Concept]
Examples: The 800th Lifetime
```

**Formula 6: "The Origins of ___"**

```
The Origins of + [Your Concept-word]
Examples: The Origins of Overchoice
```
